# Loan-Processing-Audit-and-Operational-Analysis
Operational Efficiency Audit using SQL and Power B

## Business Problem
Which bottleneck in the loan processing process wastes the most time and cost, and what improvements are required to achieve a 20% reduction in processing time?

## Project Objectives
- Analyze current loan processing performance.
- Identify operational bottlenecks.
- Calculate stage-wise processing time.
- Quantify labor costs.
- Recommend process improvements.

## Tools Used
- SQL
- Microsoft Power BI
- Excel / CSV

## Project Methodology
1. Current State Analysis
2. Bottleneck Identification
3. Cost Quantification
4. Improvement Recommendations

## Key Findings
- Total loan applications: 1,200
- Average processing time: 99.35 hours
- Main bottleneck: Underwriting
- Second bottleneck: Document Verification
- Total stage labor cost: ₹20.59 lakh

## Improvement Target
Reduce average processing time by 20%.

Baseline: 99.35 hours
Target: 79.48 hours
Potential time saving: 19.87 hours per application
